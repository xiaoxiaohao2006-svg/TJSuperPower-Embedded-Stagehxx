# TJSuperPower Embedded Stage 1

## 项目简介

TJSuperPower 嵌入式组第一阶段考核项目。

## 项目内容

### C 板基本功能

- 蜂鸣器
- LED 流水灯
- IMU 三轴数据串口打印
- DT7 遥控器通信

### 姿态与电机联动

- 姿态数据获取
- GM6020 电机控制
- 电机与姿态联动
- 联动比例控制
- 参考零点调整

### 24V 转 5V 降压板

- MP4420A
- 原理图
- PCB
- ERC 检查
- DRC 检查
